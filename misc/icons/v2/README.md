# Stemcraft Logo · v2

`logo.svg` / `logo.png` 是主方案的透明图形标记：用一笔圆润的曲线结合首字母 S 与声波的流动感。`app-icon.svg` / `app-icon.png` 把它放在软件的深蓝色底上，并给平台裁切留出空间。

| 文件前缀 | 构思 |
| --- | --- |
| `01-six-stems` | 六根圆柱直接对应分离出的六条音轨。 |
| `02-branch` | 一条输入路径分成两条输出路径。 |
| `03-s-ribbon` | 连续的 S 形声波；选为主方案。 |
| `04-six-petals` | 六条独立音轨围绕开放的中心。 |
| `05-open-track` | 类似唱片的轨道向外打开。 |
| `06-dual-wave` | 两道交错的波形表现混音。 |

每个编号方案都有可编辑 SVG 和 1024 × 1024 透明 PNG。标记统一使用软件强调色 `#4F8CFF`；SVG 图形使用 `currentColor`，便于换色。应用图标的底色为纯色 `#1C2030`，提供 1024 × 1024 方形母版，之后可按各平台要求打包。`showcase.html` 可在本地比较方案。
